# Functional Treat – Data Analyzer and Transformer

## Project Description

Functional Treat is a menu-driven Python application designed to analyze and transform numerical data using Python functions and list operations.

The project supports both one-dimensional (1D) and two-dimensional (2D) lists. It demonstrates important Python programming concepts, including built-in functions, user-defined functions, recursion, lambda expressions, and data sorting.

## Objectives

- Accept numerical data in 1D and 2D lists.
- Calculate minimum, maximum, sum, and average.
- Filter data using lambda functions.
- Calculate factorial and Fibonacci using recursion.
- Sort data in ascending and descending order.
- Demonstrate the use of *args and **kwargs.
- Return multiple values from functions.
- Display dataset summaries.

## Technologies Used

- Python 3
- Built-in Python functions
- Lists and nested lists
- Lambda expressions
- Recursive functions

## Features

1. Input Data: Accepts 1D and 2D numerical lists.
2. Data Summary: Displays total elements, minimum, maximum, sum, and average.
3. Recursion: Calculates factorial and Fibonacci sequences.
4. Lambda Functions: Filters values according to a specified threshold.
5. Sorting: Sorts data using sort() and sorted().
6. Statistics: Returns minimum, maximum, sum, and average.
7. Dataset Summary: Uses **kwargs to display dataset information.
8. Data Transformation: Uses map() and lambda to calculate squares.

## Python Concepts Implemented

- User-defined functions (UDF)
- *args and **kwargs
- Docstrings
- Recursion
- Lambda functions
- Global keyword
- Multiple return values
- 1D and 2D lists
- Sorting and data transformation

## How to Run the Project

1. Install Python 3.8 or above.
2. Download or extract the project folder.
3. Open the project folder in VS Code or any Python IDE.
4. Open the terminal.
5. Run the following command:

python functional_treat.py

6. Select an option from the menu.
7. Enter your dataset and perform the required operations.
